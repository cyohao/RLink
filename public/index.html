它是怎么工作的

每个接口由「方法 + 路径」确定。收到请求后按下面的顺序处理，保存后立即生效，不需要重启：

  1. 条件场景：从上到下检查，命中第一个就返回这个场景的内容。没有条件的场景只要启用，就会拦截所有请求，可以用来「强制返回某个错误」。
  2. 参数校验：任意一条规则不通过，就返回「校验失败时返回」的内容，用 {{error}} 可以取到错误说明。
  3. 默认返回。

路径写法：/api/box/:code 中的 :code 是路径参数，用 {{params.code}} 读取；/files/* 匹配后面任意多层路径。多个接口都能匹配同一个请求时，路径写得越具体的越优先。

返回值模板

返回值是合法的 JSON 时，系统会把其中的 {{...}} 替换成实际的值，结果以 JSON 返回；不是 JSON 时按纯文本返回。

写法说明
{{body.taskNo}}请求体里的字段，支持多层和下标：{{body.list[0].code}}
{{query.page}}URL 上的查询参数
{{params.code}}路径参数
{{headers.x-auth-token}}请求头，名称一律用小写
"{{body.quantity}}"整个字符串只有一个表达式时，保留原始类型，比如数字仍然是数字

内置函数

写法是「函数名 参数1 参数2」，字符串参数用单引号，嵌套调用时用括号括起来：{{concat 'WMS' (pad (seq 'out') 6)}}

函数说明示例 → 结果
now当前时间，可指定格式（YYYY MM DD HH mm ss SSS）{{now 'YYYYMMDD'}} → 20261026
timestamp毫秒时间戳{{timestamp}}
uuid随机 UUID{{uuid}}
seq按名称自增的序号，可指定起始值，服务重启后重新计数{{seq 'box' 1}} → 1、2、3…
randomInt随机整数{{randomInt 1 100}}
randomStr随机字符串，字符集可选 digit / upper / lower / hex / alnum{{randomStr 6 'digit'}} → 482913
pick从几个值里随机挑一个{{pick 'A' 'B' 'C'}}
pad左侧补齐{{pad 7 4}} → 0007
concat拼接{{concat 'B' body.no}}
add sub mul div加减乘除{{div body.quantity 2}}
ceil floor round min max取整和比较大小{{ceil (div 5 2)}} → 3
default值为空时使用默认值{{default query.size 20}}
if eq gt lt条件判断{{if (eq body.type 'A') '甲' '乙'}}
len upper lower number string长度、大小写、类型转换{{len body.list}}

生成列表：$repeat

在需要数组的位置写一个对象，$repeat 是次数（可以是表达式），$item 是每一项的模板。在 $item 里，{{$index}} 是从 0 开始的下标，{{$no}} 是从 1 开始的序号。

{
  "code": "0",
  "data": {
    "total": "{{body.quantity}}",
    "boxes": {
      "$repeat": "{{body.quantity}}",
      "$item": {
        "no": "{{$no}}",
        "boxCode": "{{concat 'B' (pad (seq 'box') 6)}}"
      }
    }
  }
}

参数校验

位置可选 Body、Query、路径参数、Header。字段支持多层路径，比如 order.items。Query、Header 和表单提交的值都是字符串，所以类型校验会把 "10" 当作数字；JSON 请求体则按实际类型严格校验。

接口调用

「接口调用」页可以像 Postman 一样调用任意 HTTP 接口。请求是由这台服务器发出的，所以没有浏览器跨域限制，也能访问服务器所在内网的地址。这个功能需要设置管理口令 ADMIN_TOKEN 后才能使用。

  • 地址：以 / 开头的地址（例如 /wms/api/task/out）会调用本服务自己的模拟接口；没写 http:// 时会自动补上。
  • 环境变量：在左上角「管理」里配置，例如 baseUrl、token，在地址、Params、Headers、请求体里用 {{baseUrl}} 引用。上面的内置函数也能用，例如 {{uuid}}、{{now 'YYYYMMDD'}}。
  • 替换方式：按文本替换，"qty": {{qty}} 替换后是数字，"t": "{{timestamp}}" 仍然是字符串。用到了未定义的变量时不会发送。
  • 集合：把常用的请求保存到集合里，所有人共用。
  • 历史：每次发送都会记在当前浏览器里（最多 100 条），换浏览器就看不到了。点击 ☁ 可以把某一次调用保存到服务器，所有人都能在「服务器记录」里看到，适合留作联调凭证。
  • 快捷键：Ctrl + Enter 发送，Ctrl + S 保存。
  • 实际请求：响应区的「实际请求」里能看到变量替换之后真正发出去的内容。

导出配置时会带上集合和请求，但不包含环境变量（里面可能有 token），迁移到新服务器后需要重新配置环境。

在服务器上使用

你的平台把接口地址指向 http://服务器IP:端口/你配置的路径 即可。每次调用都会记到「请求日志」里，联调时可以直接看对方实际传了什么。

导入配置

合并：同名接口（相同的方法和路径）会被覆盖，其余接口保留。
覆盖：先清空现有的全部接口，再导入。
文件里有接口调用的集合和请求时也按同样的方式处理；文件里没有时不会改动。环境变量不受影响。
